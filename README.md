# Chrome PDF Export (Obsidian)

옵시디언 **PDF로 내보내기**를 할 때 섹션·표·콜아웃이 페이지 중간에서 잘리는 문제를 해결하는 플러그인입니다.

기본 "PDF로 내보내기"를 그대로 누르면 되고, 내부적으로는 PC에 설치된 크롬(또는 엣지)으로 PDF를 만듭니다.

## 무엇이 달라지나

| | 옵시디언 기본 | 이 플러그인 |
|---|---|---|
| 섹션이 남은 공간에 안 들어갈 때 | 중간에서 잘림 | 섹션째 다음 페이지로 |
| 한 페이지보다 긴 섹션 | 아무 데서나 잘림 | 소제목(`###`)·콜아웃 경계에서 나눔 |
| 표·콜아웃 | 중간에서 잘리거나 제목만 남음 | 통째로 넘김 (한 페이지보다 길 때만 행 단위로 나눔) |
| md 안의 `page-break-after` div | 빈 페이지가 생기기도 함 | 빈 페이지 없음 |

## 설치

1. 이 저장소의 `manifest.json`, `main.js`를 볼트의 `.obsidian/plugins/chrome-pdf-export/` 폴더에 넣습니다. (폴더가 없으면 만듭니다)
2. `snippets/pdf-no-split.css`를 볼트의 `.obsidian/snippets/`에 넣습니다.
3. 옵시디언을 다시 시작합니다.
4. 설정 → 모양 → CSS 스니펫에서 `pdf-no-split`을 켭니다.
5. 설정 → 커뮤니티 플러그인 → 제한 모드 끄기 → **Chrome PDF Export**를 켭니다.

PC에 크롬이나 엣지가 설치되어 있어야 합니다. 데스크톱 전용입니다.

## 사용

평소처럼 노트 탭 ⋯ 메뉴 또는 `Ctrl+P` → **PDF로 내보내기**.

- 용지 크기는 옵시디언 PDF 내보내기 설정(A4 등)을 따르고, 여백은 15mm입니다.
- 소제목은 `**굵은 글씨**`보다 `### 제목`으로 쓰면 그 자리에서 깔끔하게 나뉩니다.

## 동작 방식

1. 노트를 옵시디언 렌더러로 HTML로 만들고, 현재 테마·스니펫 CSS를 함께 담습니다.
2. 크롬 안에서 블록 높이를 재서 페이지를 나눌 위치를 직접 정합니다.
   - 섹션(`#`, `##` 제목부터 다음 제목 전까지)이 남은 공간에 안 들어가면 새 페이지에서 시작
   - 섹션이 한 페이지보다 길면 `###`·콜아웃 경계에서, 그것도 길면 블록 경계에서 나눔
3. 크롬 headless로 PDF를 출력합니다.

옵시디언에 들어 있는 크롬 엔진은 버전이 낮아 `break-before: avoid` 같은 CSS를 일부 무시하기 때문에, PC의 최신 크롬으로 출력합니다.

## CSS 스니펫만 쓰기

플러그인 없이 `snippets/pdf-no-split.css`만 넣어도 옵시디언 기본 내보내기가 꽤 좋아집니다. 다만 내장 엔진 한계로 한 페이지보다 긴 섹션은 일부 중간에서 나뉠 수 있습니다.
